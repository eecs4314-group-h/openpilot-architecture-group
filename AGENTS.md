# Group H Website — Project Instructions

## Public Website Content and Academic Integrity Rules

1. The public website represents the students' academic project, not the AI agent's development process.
2. Never publish Codex instructions, prompts, audit logs, troubleshooting notes, or internal progress reports as website content.
3. Never describe changes requested by the user as academic accomplishments.
4. Distinguish between internal developer documentation and public academic content.
5. Public-facing text must be relevant to the academic assignment and supported by the group's actual work.
6. Before adding content, ask: "Would this information belong on a university group project website?"
7. If the answer is no, keep it in internal documentation or omit it.
8. Preserve legitimate assignment-required disclosures, including any required AI-use statement.
9. Don't add decorative alerts, warning boxes, audit notices, or administrative status summaries without a genuine academic purpose.
10. Apply these rules to ALL future assignments, reports, presentations, and website updates in this repository.
